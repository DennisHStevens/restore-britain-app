# Logos

Place official Restore Britain logo files here.

## Required files:

- `logo-full.svg` — Full logo (text + icon) in SVG format. Primary usage: headers, login page.
- `logo-icon.svg` — Icon-only version in SVG format. Primary usage: PWA icons, favicons, compact spaces.
- `logo-full-white.svg` — White/inverse version for dark backgrounds.
- `logo-icon-192.png` — 192x192 PNG for PWA manifest (generated from SVG).
- `logo-icon-512.png` — 512x512 PNG for PWA manifest (generated from SVG).
- `favicon.ico` — Standard favicon (generated from SVG).

## Notes:
- SVG is the source of truth — PNGs are generated from it.
- If the party only provides PNG/JPG logos, we'll need the highest resolution available and will trace to SVG if necessary.
- All files should be on a transparent background unless specifically noted.
